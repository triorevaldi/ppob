# PPOB — Workshop Manager

Browser-based workshop management app. Current version includes a Dashboard and Income Manager.

## Data
Income records are stored in browser localStorage. No account or login is required.

## Current fields
- Item name
- Qty
- Income amount (IDR)
- Date (dd/mm/yyyy, automatically set to current date)
- Note
- Edit/Delete actions

## Planned
